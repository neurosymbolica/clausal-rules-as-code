# Six-case exploratory paired pilot — protocol frozen before inference

This separate extension leaves GDPR-30 and its 70 original questions unchanged. Six synthetic boundary cases, two questions each. Four requested models: gpt-6.1-sol, gpt-6-astra, claude-opus-5-5, claude-sonnet-5-5. Three parallel conditions: law; law+RIS decisions; law+Mike demo output (not cumulative with RIS). One fresh batch containing all six cases per model/condition: 12 calls, 72 case-condition records, 144 question answers if all succeed. No retries of successful inference, no fallback substitution. Missing runs remain missing.

All conditions receive identical case narratives, normalized facts, omission notes and coverage limitations. Common law includes relevant full GDPR articles plus Austrian DSG sections5/30 (retrieved via RIS but statutory text is common to all). RIS treatment adds two complete DSB decisions previously retrieved through RIS MCP. Mike treatment adds only actually returned exploratory outputs for the frozen facts. No reviewed gold, evaluator notes or other models' answers enter prompts. No held-out bypass. Unknown fields are omitted; E06 deliberately sends conflicting flags. No engine support is invented for E05 or time-computation questions.

The primary comparison is within-model answer quality: Mike minus law on identical questions; RIS minus law is a secondary comparison. Decision-label agreement alone is insufficient. Assistant assessment: 0 = materially wrong/unsafe conclusion or reasoning, 1 = correct core conclusion but material critical-point omission, 2 = correct conclusion and all three critical points substantively addressed. A materially correct qualified answer may receive2 despite alternate label wording; label agreement is reported separately. Cite excerpt/reason for every deduction. Report improved/unchanged/worse questions and case-level summed score changes. The rater is the same assistant preparing the study, not an independent lawyer; blind IDs are a review aid, not independent blinded validation. Gold is provisional.

H0: no within-model quality improvement from the demo supplement. H1: higher quality with the demo supplement. Six cases are clusters; questions/models are not independent samples. Report a descriptive effect and exact paired sign test on nonzero case-level deltas (averaged across available paired models), exploratory only, no significance-based superiority claim, no power claim. Report missing/held-out/unsupported coverage alongside scores. A ceiling result cannot establish equivalence. Underlying CLI harnesses differ by provider, so cross-provider rankings are exploratory. Medium effort is not equal compute across providers. Costs from subscription routes are not invoices; record emitted usage and any provider cost estimate separately.

Supplied-fact retrieval is intentional: this tests answer generation with evidence, not autonomous tool selection or fact extraction. Models may reject tool outputs contradicted by facts/law. New input interpretations and source ordering remain possible confounds. No external human review, immutable backend guarantee, full production-API test or complete GDPR-Prolog validation is claimed.
